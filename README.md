# UFO Controller

VORZE 製 BLE デバイス（UFO-TW / UFO SA）を Windows PC から操作するデスクトップアプリです。

> **本アプリは VORZE 製品のメーカー非公式の個人開発ツールです。**
> VORZE・UFO-TW・UFO SA は各社の商標・登録商標です。
> 本ツールはこれらのメーカー・ブランドとは一切無関係です。

## ダウンロード

**[最新版をダウンロードする](https://github.com/nosemako/ufo-controller/releases/latest)**

ダウンロードするファイル: `UFOController-v1.0.0.zip`

## 動作環境

| 項目 | 要件 |
|------|------|
| OS | Windows 11（動作確認済み） |
| Windows 10 | 未検証（動作を保証しません） |
| Bluetooth | BLE（Bluetooth 4.0 Low Energy）対応の PC またはアダプタ |
| Python | 不要（exe 版） |

**WSL2・Linux・macOS では動作しません。** Windows ネイティブ環境で実行してください。

---

## インストール手順

1. `UFOController-v1.0.0.zip` をダウンロードする
2. zip ファイルを任意の場所に展開する（**zip 内から直接起動しないこと**）
3. 展開したフォルダをデスクトップなど書き込み可能な場所に置く
4. `UFOController.exe` をダブルクリックして起動する

展開後のフォルダ構成:

```
UFOController/
  UFOController.exe    ← ダブルクリックで起動
  _internal/           ← 削除不可（Python ランタイム一式）
  マニュアル.md        ← 詳細な使い方
  logs/                ← 起動時に自動生成
```

---

## 起動方法

1. PC の Bluetooth をオンにする
2. UFO-TW または UFO SA の電源を入れる
3. `UFOController.exe` をダブルクリックして起動する
4. 画面の「スキャン＆接続」ボタンでデバイスを検出する

---

## 重要な注意事項

### `_internal` フォルダを削除しないこと

`_internal/` フォルダには Python ランタイムと依存ライブラリが含まれています。
**削除するとアプリが起動しなくなります。** 削除してしまった場合は zip を再展開してください。

### SmartScreen 警告について

初回起動時に「Windows によって PC が保護されました」という画面が表示される場合があります。
「詳細情報」→「実行」を選択することで起動できます（本アプリは署名なし exe のため）。

### Bluetooth 接続時の注意

BLE は同時に 1 つのアプリからしか接続できません。
VORZE 公式アプリなど他のアプリがデバイスに接続中の場合は、そのアプリを終了してから本アプリで接続してください。

### 初回使用時

低速（speed ≤ 10）・短時間（3 秒以下）での動作確認を推奨します。

## トラブルシューティング

### デバイスが見つからない

- PC の Bluetooth がオンになっているか確認してください
- デバイスの電源が入っているか確認してください
- PC にデバイスを近づけてください（推奨: 1 m 以内）
- VORZE 公式アプリなど他のアプリがデバイスに接続中の場合は検出できません。他のアプリを終了してから再試行してください

### 起動できない（DLL エラー等）

- `UFOController.exe` と同じフォルダに `_internal/` が存在するか確認してください
- zip を展開してからフォルダごと実行してください（zip 内から直接起動しないこと）
- デスクトップなど書き込み可能な場所に展開してください（`C:\Program Files` 等は不可）

### `_internal` を削除してしまった

zip ファイルを再度展開し、フォルダ全体を置き換えてください。

### Bluetooth が無効

Windows の設定 → Bluetooth とデバイス で Bluetooth をオンにしてください。
